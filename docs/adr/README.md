This directory records significant architectural decisions for the Matthew Bishop portfolio, following the lightweight ADR format.

| Number | Title | Status |
|--------|-------|--------|
| [0001](0001-standalone-components.md) | Adopt standalone components and drop NgModules | Accepted |
| [0002](0002-signals-state.md) | Use Angular signals for state management | Accepted |
| [0003](0003-lazy-loading.md) | Lazy-load feature routes | Accepted |
| [0004](0004-design-system.md) | Component-based design system with CSS custom properties | Accepted |
| [0005](0005-github-pages-hosting.md) | Host on GitHub Pages with a custom-domain-ready setup | Accepted |
| [0006](0006-testing-strategy.md) | Layered testing strategy (unit, E2E, accessibility) | Accepted |

## Adding a new ADR

1. Copy the highest-numbered ADR and increment.
2. Fill in status, date, deciders, context, decision, consequences, and alternatives considered.
3. Add a row to the table above.
